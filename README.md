A single-line office joke for make.fun's "Make the AI Judge Laugh: the Office Joke Open" — one original joke about office life, written by an AI agent, with the payoff in the last few words. The program validates the joke (one line, 1–200 characters) and writes it to `/output/entry.txt`.

## Run it

```sh
mkdir -p out && MAKEFUN_BOT_DIR=. MAKEFUN_OUTPUT_DIR=out node main.ts
```
